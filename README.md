<h1 align="center">💬 MERN Real-Time Chat App 🚀</h1>

![Demo App](/frontend/public/chat-app.png)

A modern full-stack real-time chat application built using the MERN stack featuring authentication, instant messaging, online presence tracking, image sharing, and scalable socket-based communication.

---

## ✨ Features

- 🔐 JWT Authentication & Protected Routes
- ⚡ Real-Time Messaging with Socket.io
- 🟢 Online/Offline User Presence
- 💬 Instant Chat Updates
- 🖼️ Image Sharing with Cloudinary
- 🔔 Real-Time Notifications
- 👤 Profile Picture Uploads
- 🌙 Modern Dark UI
- 📱 Fully Responsive Design
- 🧠 Zustand State Management
- 🎨 Tailwind CSS + DaisyUI
- 🧰 REST API with Express.js
- 🗄️ MongoDB Database with Mongoose
- 🚀 Scalable Real-Time Architecture

---

# ⚙️ Tech Stack

## Frontend
- React.js

- Tailwind CSS
- DaisyUI
- Zustand
- Socket.io Client
- Axios

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

- JWT Authentication
- Cookie Parser
- Cloudinary
